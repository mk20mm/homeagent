## 不可违反的不变量（改任何代码前先读）

1. **契约先行**：接口变更先改 `api/openapi.yaml` ➔ 运行代码生成脚本。禁止手改生成文件。
2. **主键与核心数据约束**：主键全 UUID；金额全为整数分；禁止使用 float 存储货币。
3. **写操作全量可撤销**：所有修改状态的工具调用必须产出 `undo_id`，提供 24h 逆向回滚保障。
4. **权限双保险**：提示词源头工具过滤 + 执行器运行时校验双层防护。
5. **禁止手写原生 HTTP 请求**：前端统一走类型安全的封装客户端，禁止裸调用 fetch。
6. **边界解析**：外部不信任输入在网关与接口层强校验，领域层不做防御性脏检查。
7. **分层依赖单向流动**：严格遵守 `API ➔ Domain ➔ Store` 依赖规则，严禁逆向耦合。
8. **错误三段式标准**：`{ code, message, trace_id }`，禁止向客户端暴露未脱敏堆栈。

## 目录地图

```

web/ (或 src/frontend)      # 前端应用与 UI 组件
docs/                       # 核心文档与领域知识库

scripts/                    # 自动化脚本（环境、生成、自检）
```

## 本机环境注意（踩过的坑）

- **网络代理**：本地请求注意绕过系统代理（如添加 `--noproxy "*"`）。
- **文件编码**：避免脚本生成 BOM 导致 JSON 解码失败；中文脚本保证无乱码。
- **端口清理**：重启服务前必须杀死占用端口的僵尸进程。

## 工作方式（Harness）

- 人定方向、定约束、验结果；执行交给智能体。
- 卡住时不要"更努力"，问：**缺什么能力/文档/约束，才能让智能体可靠地做出来？** 答案写进本文件或 docs/。
- 每次改动同步更新执行计划与技术债。
