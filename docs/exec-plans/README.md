## 写作约定

- 每份计划含：目标、任务清单（带状态）、**决策日志**（为什么这么选，含被否的方案）、验收标准。
- 完成后整体移入 `completed/`，不移除（决策历史比代码更难重建）。
- 新增计划先在 `active/` 建文件，再在此登记一行。
