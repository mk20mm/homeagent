# ADR-007：本地写入可撤销，真实设备动作提供取消与补偿

- 状态：设计采用，尚未实施
- 日期：2026-10-01
- 背景：用户明确要求第一步围绕财务、家务、厨房，家务能控制实际家庭设备并反馈执行情况。原 ADR-004 将所有写操作视为可逆数据库写，不能表达已经发生的清扫/烹饪。

## 决策

工具分为 read、local_write、device_command。本地账单/任务/菜谱配置修改继续要求 Undo、24h 窗口、事务和审计；本地状态的恢复不声称能恢复已经发生的物理行为。设备命令要求持久化命令、能力与动作授权、真实状态协调、取消/补偿协议。

queued 命令可以取消，已经发出的扫地命令只能请求暂停/返航；已扫地面不可撤销。智能灯恢复旧状态是条件补偿，需要验证没有后续外部修改；无法确认则不盲目覆盖。第一阶段不自动启动加热、支付或高危设备。

启动动作超时/进程崩溃后进入 unknown 并协调，不自动重发；内部操作键只防 HomeAgent 重复派发，不能证明外部 exactly-once。恢复动作也须校验权限与能力并留痕。

## 后果

解决真实设备接入与“全量可撤销”承诺冲突；结果卡片区分撤销、取消、暂停、返航。实现需分离 UndoableWrite 与 DeviceCommand 接口，不可以给 DeviceCommand 填无效 Undo()。本 ADR 修订 ADR-004 在外部设备动作上的适用范围，详细行为及验收见 [架构](../homeagent-v1-architecture.md) 和 [验收](../homeagent-v1-acceptance.md)。

## 备选

强行把暂停叫撤销会误导用户；放弃真实设备会违背第一阶段产品目标。采用不同恢复语义，以代码声明和实测能力保证事实清楚。
