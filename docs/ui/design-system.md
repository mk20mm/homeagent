# 家事 Agent · UI 设计系统

风格定位：**苹果简约风（类似 Grok Bot / Apple Health）** —— 大留白、圆角卡片、毛玻璃、无衬线、克制的彩色点缀。

## 色彩

| 用途            | 色值      | 说明                  |
| --------------- | --------- | --------------------- |
| 主背景          | `#F2F3F7` | 浅灰底，不刺眼        |
| 卡片背景        | `#FFFFFF` | 纯白卡片              |
| 主强调色        | `#0A84FF` | 苹果蓝，用于按钮/链接 |
| 次强调色        | `#8E8E93` | 灰，用于次要文字      |
| 成功            | `#34C759` | 苹果绿，打卡成功      |
| 警告            | `#FF9500` | 橙，提醒/超支         |
| 危险            | `#FF3B30` | 红，撤销/删除         |
| 紫色（AI 主题） | `#7C3AED` | Agent 对话气泡/图标   |

## 字体

- 系统字体栈：`-apple-system, "SF Pro", "PingFang SC", "Microsoft YaHei", sans-serif`
- 大标题 22pt / 标题 17pt / 正文 15pt / 说明 12pt

## 圆角与间距

- 卡片圆角 16px，按钮圆角 12px，小标签 8px
- 页面边距 16px，卡片间距 12px，元素内距 14px

## 关键视觉元素

- **对话气泡**：用户蓝（#007AFF）、AI 纯白圆角轻阴影卡片（#FFFFFF，带 0.5px 浅边框）
- **豆包式思考与执行流**：柔和深色卡片（#1C1C1F），顶端微弱文字“已处理 X 秒”配细虚线（rgba(255,255,255,0.12)），思维短句与微动作胶囊（rgba(255,255,255,0.06)）交错排列
- **结构化步骤卡片**：浅灰底（#FBFBFD），实心蓝色圆形数字徽章（#007AFF，白色数字），加粗标题，浅蓝微导引框（rgba(0,122,255,0.08)）
- **核心建议 Callout 盒**：暖黄底（#FDF6EC），橙黄边框（rgba(230,162,60,0.25)），深褐黄说明文字（#7D5218）
- **权威信源与 Jev 智能精排卡片**：毛玻璃磨砂（rgba(255,255,255,0.88)），右上角 Jev 紫色渐变激活按钮（#5856D6 ~ #AF52DE），高可信绿色胶囊（#34C759），降权灰色胶囊（#8E8E93）
- **结果卡片**：白底 + 轻阴影 + 右上角「撤销」次级按钮
- **列表项**：左到右图标-文字-状态，极细分隔线（#E5E5EA）
- **底部 Tab 栏**：毛玻璃半透明，4 个入口
