# UI 页面设计

一期（MVP）全部交互页面，统一**苹果简约风**（大留白、圆角卡片、毛玻璃、蓝紫点缀），390×844 iPhone 尺寸。

## 页面清单

### 移动端（家人日常使用）

| 页面     | 文件                 | 说明                                                                  |
| -------- | -------------------- | --------------------------------------------------------------------- |
| 对话主页 | `page-01-chat.png`   | AI 交互入口：气泡对话、记账撤销卡片（紫框）、会话内切模型、底部输入栏 |
| 家务分工 | `page-02-chores.png` | 今日任务（我的+家庭）、打卡勾选、完成统计、积分                       |
| 家庭账本 | `page-03-money.png`  | 本月支出 Hero 卡、预算进度条、分类占比、最近流水                      |
| 报饭     | `page-04-meal.png`   | 今晚在家人数、成员报饭状态、一键报饭                                  |
| 系统管理 | `page-05-admin.png`  | 供应商开关、模型切换、用量统计、成员权限矩阵、审计入口                |

### Web 管理端（家长/管理员，Ant Design 风格，1440×900）

| 页面       | 文件                   | 说明                                                                        |
| ---------- | ---------------------- | --------------------------------------------------------------------------- |
| 对话调试台 | `web-01-debug.png`     | 左侧调试对话 + 右侧 ReAct 执行轨迹（风险等级/参数/权限校验/撤销），排错利器 |
| 系统管理   | `web-02-admin.png`     | 供应商表格（Key/连接测试）、提醒规则中心（Cron 可视化）、用量统计卡         |
| 仪表盘     | `web-03-dashboard.png` | 支出趋势柱状图、分类占比、最近动态、超支预警                                |

**两端关系**：共用同一套 Go 后端 API（`/api/v1`），数据同源。移动端对话为主入口；Web 端管理为主，保留对话调试台用于测试 Agent 与排查工具调用。

## 设计系统

见 `design-system.md`：主背景 #F2F3F7、主强调 #0A84FF、AI 紫 #7C3AED、成功绿 #34C759、警告橙 #FF9500、危险红 #FF3B30。

## 设计原则

- **对话即交互**：大部分操作从对话主页发起，结果以卡片回流（可撤销）
- **页面是补充**：家务/记账等高频页提供列表化视图，但对话入口始终在底部 Tab 第一位
- **老人/小孩友好**：大字体、高对比、常用操作一键完成（报饭单按钮）
