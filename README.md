# 家事 Agent（HomeAgent）

仓库：https://github.com/mk20mm/homeagent

> 一个以 AI 对话为主入口的家庭协作中枢：家人说一句话，Agent 自动把家务、用餐、日程、账单、购物安排到位，并主动提醒、定期复盘。

## 本地开发

```bash
git clone https://github.com/mk20mm/homeagent.git
cd homeagent
make generate   # ent + OpenAPI + 前端 schema
make migrate    # 建库 + 种子数据
go run ./cmd/homeagent
```

前端（pnpm 工作区）：`pnpm install` 后 `pnpm -r run dev`（web :5173 / admin :3001）。

## 这是什么

面向单家庭自用的智能协作工具。不让大家多学一个"管理系统"，而是把所有家庭事务都装进一个对话窗口——**动嘴，系统跑腿**。

## 为什么做

家庭里最耗神的不是某件大事，而是每天重复的碎事："今晚吃什么""轮到谁洗碗""卫生纸是不是快没了""这笔账记了没"。传统 App 把每件事做成独立入口，家人不愿打开；这个项目用**一个 AI 助手 + 若干可调度的后端工具**，让一句话完成一件事。

## 核心特性

- **对话即执行**：统一对话窗口，Agent 识别意图后调用后端工具，执行结果以卡片回显，可一键撤销/修改
- **模型随心切**：对话窗口内可直接切换已配置的模型（海外/国内/本地），不绑定单一供应商
- **主动服务**：到点提醒、耗材不足预警、账单到期、每周家庭小报，不用主动打开就有
- **跨模块联动**：菜谱缺食材自动进购物清单，购物完成自动记账，家务任务自动入日历
- **多角色适配**：可配置权限矩阵（成员 × 模块开关），小孩/老人/合租各有预设模板，界面可简化
- **多端覆盖**：Web/PWA 打通手机与桌面，日程可订阅到 iOS/Google 系统日历，提醒不漏

## 模块一览

| 模块        | 说明                                                                                                                                          |
| ----------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| AI 交互入口 | 统一助手、工具调度、结果卡片、主动推送、会话内切换模型                                                                                        |
| 家务分工    | 任务库、指派认领、打卡、提醒催办（轻量版，排班/积分后补）                                                                                     |
| 家庭日程    | 共享日历、农历生日/纪念日、周期提醒、iCal 订阅                                                                                                |
| 家庭财务    | 对话记账、自动归类、预算提醒、账单到期                                                                                                        |
| 购物囤货    | 协同清单、耗材余量监控、不足自动补货                                                                                                          |
| 用餐场景    | 吃啥推荐、报饭人数统计、菜谱补食材、外卖记账                                                                                                  |
| 系统管理    | AI 供应商配置（海外/国内/本地，Key 加密、连接测试、模型清单）、会话切模型、用量统计、操作审计、成员权限矩阵、家庭设置、通知设置、数据备份导出 |
| 幸福度包    | 夸夸墙、仪式感提醒、AI 家庭周报（三期）                                                                                                       |

## 技术栈

| 层         | 选型                                                                                          |
| ---------- | --------------------------------------------------------------------------------------------- |
| 后端语言   | **Go**                                                                                        |
| Web 框架   | Gin（中间件生态好）                                                                           |
| 数据层     | **ent**（schema 即代码、类型安全强、迁移友好）；SQLite 起步，可平滑迁 Postgres                |
| LLM 客户端 | `go-openai`（OpenAI 兼容，支持流式 + 工具调用）+ 自建统一 LLM 网关，适配海外/国内/本地 Ollama |
| Agent 调度 | 自建轻量工具调度器（工具注册表 + Function Calling 执行 + 结果回流）                           |
| 接口契约   | OpenAPI 3.0 → oapi-codegen 生成 Go server 桩 + TS client（补前后端类型共享）                  |
| 认证       | golang-jwt + 会话 + 权限矩阵                                                                  |
| 定时任务   | robfig/cron（提醒/账单到期/周报）                                                             |
| 前端       | Vite + React + TS（SPA）+ PWA                                                                 |
| 移动端     | Expo（三期）                                                                                  |
| 部署       | VPS + Docker + Caddy/Nginx                                                                    |

### 为什么选 Go

- **性能/并发**：goroutine 天然适合流式输出、长连接、定时任务，三者在本项目都是刚需
- **长期安全/扩展**：静态类型 + 内存安全 + 少依赖，供应链风险低，上限最高
- **部署省心**：单二进制 + Docker，适合自用单 VPS
- 代价：AI 生态弱，Agent 调度框架需自建（反而更可控）；与前端语言不通，靠 OpenAPI 契约生成 client 桥接

## 路线图

- **一期 MVP**：Agent 内核 + 系统管理（供应商配置/用量/审计/权限）+ 家务（轻量）+ 记账 + 报饭统计 —— 跑通最高频的"对话→执行"闭环
- **二期**：日程与日历同步 + 购物囤货 + 吃啥推荐/菜谱补食材 —— 模块联动
- **三期**：幸福度包 + 家务排班/积分 + App 打包

## 明确不做

外卖直接下单（平台 API 不开放）、AA 结算、多租户、企业级项目管理、通用闲聊、电商比价、自动场景路由与故障转移（用会话内手动切换模型替代）。
